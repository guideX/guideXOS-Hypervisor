RISCV-27 deterministic fixture
------------------------------
Source fixture: tests/fixtures/riscv_linux_process_lifecycle/
The static freestanding RV64 ELF uses no libc, interpreter, BusyBox, separate
child executable, or host-created task. It opens /dev/ttyS0, writes the
parent-initialized marker, initializes private writable data, and invokes
Linux v6.12's RISC-V clone ABI. The child checks getpid/getppid, writes and
reads its COW value, emits a marker, yields eight times, and calls exit(37).
The parent verifies its original value, waits for the child, validates
37<<8, confirms -ECHILD with WNOHANG, emits its success marker, and remains
alive in a getpid/sched_yield loop.

  GCC cross compiler: riscv64-linux-gnu-gcc 13.3.0
  GNU readelf/objdump: binutils 2.42
  Python 3.12.3; DTC 1.7.0
  Archive: uncompressed newc, deterministic entry order and metadata
  uid/gid: 0; fixed mtime: 0; /init mode: 0100755
  Entries: ., dev, dev/console, dev/ttyS0, init, TRAILER!!!
  ELF: ET_EXEC, RV64, entry 0x10000, no interpreter
