--- Phase RISCV-1: decoded vs actually executed ---

Instructions decoded (production riscv::Decoder, unchanged this phase):
- Full RV64I/RV64M/Zicsr/SYSTEM/RV64A/RV64C decode coverage listed above.
  Decode-only coverage is NOT execution.

Instructions actually executed (RV64CPU::step, genuine semantics):
- LUI, AUIPC, ADDI, ADD, SUB, LD, SD, BEQ, BNE, JAL, JALR
- EBREAK (32-bit) and C.EBREAK are explicit Halt outcomes, not Ok.

Tested CPU semantics (test_riscv_minimal_execution, 173 runtime checks):
- x0 hardwired zero (direct writes and ADDI x0 ignored)
- Signed immediates (ADDI -1/-2, S-immediate, B/J offsets incl. negative path via wraparound)
- 64-bit wraparound arithmetic (0xFFFFFFFFFFFFFFFF + 10 = 9)
- PC-relative addressing (AUIPC) and JAL/JALR link = PC+4
- JALR low-bit clearing ((rs1+imm) & ~1, proven with odd offset 13)
- Branch taken (BEQ skips) and not-taken (BNE falls through)
- Little-endian LD/SD round-trip incl. sign-extended LUI patterns, raw byte verification
- Reset determinism (PC=base, regs=0, counters=0; fresh CPU PC=0)
- Failure containment: Illegal / Unsupported / FetchFault (truncated + out-of-range) /
  MemoryFault (LD/SD OOB, rd preserved, PC unchanged)
- Compressed instructions never report Ok (Unsupported; C.EBREAK reports Halt)
- Instruction-count bounds (50-step infinite JAL x0,0 loop terminates by harness bound)

Explicitly unsupported operations (valid decode -> StepOutcome::Unsupported):
- Every other decoded mnemonic: LB/LH/LW/LBU/LHU/LWU, SB/SH/SW, BLT/BGE/BLTU/BGEU,
  SLTI/SLTIU/XORI/ORI/ANDI/SLLI/SRLI/SRAI, SLL/SLT/SLTU/XOR/SRL/SRA/OR/AND,
  ADDIW/SLLIW/SRLIW/SRAIW, ADDW/SUBW/SLLW/SRLW/SRAW, all RV64M, all RV64A,
  all CSR/ECALL/MRET/SRET/WFI/FENCE forms, all compressed except C.EBREAK.

Remaining architectural requirements for Linux boot (NOT in RISCV-1):
- Full CSR file + privileged traps (ecall/mret/sret/wfi semantics, trap vectors)
- MMU/page tables (Sv39/Sv48), SFENCE.VMA behavior, fault reporting
- SBI interface for the guest kernel
- Full integer coverage (shifts, compares, word ops), F/D floating point, full C extension
- PLIC/CLINT, UART/virtio device emulation, timer/interrupt delivery
- ELF loader integration and boot Hart state machine
